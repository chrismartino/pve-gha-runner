Self-hosted GitHub Actions runners on Proxmox, one LXC per job.

Shell scripts that create unprivileged Ubuntu 24.04 LXC containers on Proxmox VE and register them as GitHub Actions runners. Run a single persistent runner, or a self-healing pool where every job gets a fresh container.

Get started View on GitHub

Features

Ephemeral pool

Each runner registers with --ephemeral, runs exactly one job, powers off, and is destroyed and replaced. No state carries between jobs.

GitHub App auth

Signs a short-lived JWT, exchanges it for an installation token, and requests the registration token. No long-lived PAT is stored or passed into containers.

Unprivileged containers

Built for Proxmox VE 9 (LXC 6, cgroup v2) so Docker can work inside unprivileged containers.

Multi-repo

One hookscript serves every repo. Each container is tagged repo-<slug> and reads its own config, with a per-repo MAX_RUNNERS cap.

Extra dependencies

Point EXTRA_INSTALL_SCRIPT at a script to install Docker or any CLIs your jobs need. An example is included.

Verified runner download

Resolves the latest actions/runner release at run time and checks it against GitHub's published SHA-256 when available.

How the ephemeral pool works

  1. The create script builds an LXC container, installs the runner, and registers it with --ephemeral.
  2. A one-shot systemd unit runs the job, then powers the container off.
  3. The Proxmox post-stop hookscript destroys the container and runs the create script again for its replacement.
  4. A per-container flap guard stops a broken registration from respawning in a loop.

A persistent mode is also available: one long-lived container installed with svc.sh.

Quick start

You need Proxmox VE 9, openssl and curl on the host, and a GitHub App installed on your repository.

git clone https://github.com/chrismartino/pve-gha-runner.git
cd pve-gha-runner

# Persistent runner
./create-pve-lxc-gha-runner.sh

# First container of an ephemeral pool
EPHEMERAL_RUNNER=true \
GITHUB_APP_ID=123456 \
GITHUB_APP_PRIVATE_KEY_PATH=/root/my-app.private-key.pem \
OWNERREPO=someorg/somerepo \
./create-pve-lxc-gha-runner.sh

Ephemeral mode also needs the hookscript copied to a snippets storage and a per-repo config in /etc/gha-runner/. The README has the full steps.

Security notes

Use these runners with private repositories. On a public repository, a pull request from a fork can run arbitrary code on a self-hosted runner. Ephemeral containers limit the damage but do not make that safe.
  • The App's private key stays on the Proxmox host and is never copied into a container.
  • The registration token is pushed in as a file, so it does not appear in host ps output.
  • The scripts run as root on your Proxmox host. Read them before you run them.

To report a vulnerability, use the repository's Security tab.
